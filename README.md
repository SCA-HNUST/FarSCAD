# FarSCAD Website and Code

This repository contains the FarSCAD (Far-field Side-Channel Attack Dataset) website and related experimental code.

## Website

The website is built with HTML, CSS, and JavaScript and is hosted using GitHub Pages.

## Code

The `code/` directory contains the experimental code related to the FarSCAD dataset, including AES, SM4, and Kyber.

## Preview Locally

Open `index.html` directly, or serve the folder with any static file server.
