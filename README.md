# Screaming Channels GitHub Pages Site

This folder is a self-contained static website.

## Preview locally

Open `index.html` directly, or serve the folder with any static file server.

## Publish with GitHub Pages

1. Create a repository or use an existing one.
2. Copy everything in this folder to the repository root.
3. Commit and push the files.
4. In **Settings → Pages**, select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then save.

Replace the placeholder paper and dataset links in `index.html` with your real URLs before publishing.
